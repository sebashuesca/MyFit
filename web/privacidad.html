Política de Privacidad

Última actualización: 2 de octubre de 2026.

Datos de la aplicación

MyFit está diseñada para almacenar los datos de entrenamiento y nutrición localmente en el dispositivo mediante Room DB y funcionar sin conexión. La aplicación se encuentra en fase beta; las características disponibles pueden variar entre compilaciones.

Uso de este sitio

Esta landing no incluye formularios de registro ni herramientas de analítica propias. Para mostrar la tipografía y utilidades visuales, el navegador puede conectar con Google Fonts y jsDelivr. Esos servicios reciben la información técnica habitual de una solicitud web, como la dirección IP y datos del navegador.

Descarga externa

El botón de descarga dirige a GitHub Releases. La descarga y las solicitudes realizadas allí se rigen por la declaración de privacidad de GitHub.

Consultas

Para solicitar información o reportar un problema de privacidad, utiliza el repositorio de MyFit en GitHub.
